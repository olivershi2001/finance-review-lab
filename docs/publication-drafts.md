## Website project description

Finance Review Lab is an original benchmark project exploring whether AI can audit financial models without breaking correct work. It combines synthetic Excel cases, explicit financial conventions, reference calculations and a conservative grading workflow. The public development suite is designed to make the method inspectable; a separate frozen evaluation set is planned for future capability measurements.

The local results explorer separates simulated software fixtures, development trials and scored evaluations. Review experiments compare an initial audit with self-review and independent feedback. The project is being prepared for release; no model leaderboard or performance finding is claimed here.
